TITLE:
FastAnimation: 300 Spheres + 50,000 Particles at 60 FPS (Zero-GC FastJava Engine)

DESCRIPTION:
What happens when you push Java's raw math and software rasterization to the absolute limit?

In this demo, FastAnimation orchestrates 300 independent FastTween spheres (Quad-InOut easing) alongside 50,000 live 3D particles that dynamically orbit, track, and migrate across the spheres in real-time.

Zero GC-stutters. Zero external dependencies. Zero GPU bloat. Just pure, contiguous memory arrays, native Windows DWM timing, and mathematical precision.

🔥 TECHNICAL HIGHLIGHTS:
- ⚡ 50,000 Dynamic Orbit Particles: Contiguous float-array memory buffers with 3D perspective projection and phosphor decay trails.
- 🪐 Gravitational Sphere Migration: Particles smoothly transfer across 300 tweened target spheres with tri-radial orbital spans.
- ⏱️ Native Heartbeat Timing: Hooked directly into Windows Multimedia Timers (FastDWM / FastExecution) for ~1ms precision loops without OS scheduler jitter.
- 🛡️ Zero-Allocation Hotpath: 100% allocation-free render pipeline—no object churn, eliminating Garbage Collection stalls entirely.
- 🎨 Immersive Dark Aesthetic: FastTheme native Win32 window integration with seamless black-and-white phosphor contrast.
